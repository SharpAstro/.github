# Sponsors

Everything SharpAstro publishes is free and stays free. Every feature, every build and every
library ships to everyone, sponsor or not, and no tier changes that.

What sponsorship pays for is the part writing code does not cover: bench hardware to test drivers
against, CI minutes, Git LFS bandwidth, and the Microsoft Store developer account. A driver can
only really be fixed against the device it drives, and most of the hardware support here is
written against protocol documentation and simulators, so a mount or a camera on the bench is the
difference between a plausible fix and a verified one.

- **[GitHub Sponsors](https://github.com/sponsors/SharpAstro)** — monthly or one-time, with tiers.
- **[Buy Me a Coffee](https://buymeacoffee.com/sharpastro)** — one-off, no account needed. This is
  the one the apps link to, and it stays plain: nothing is ever given in return through it.
